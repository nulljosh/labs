# labs

`~/Documents/Code` is this repo. Small projects live here as plain folders with their history kept, and CI for each one sits at the root in `.github/workflows/<name>-*.yml`. Bigger products have their own repos, sit next to these folders, and are gitignored here.

## In labs

**Apps and sites:** [bcgd](./bcgd), [homeqi](./homeqi), [dream](./dream), [cadence](./cadence), [fieldbook](./fieldbook)

**Tools:** [tripwire](./tripwire), [hormuz](./hormuz), [keyrate](./keyrate), [weather](./weather), [authmail](./authmail), [dotfiles](./dotfiles), [scripts](./scripts)

**Experiments:** [bank](./bank), [credis](./credis), [canlii-app](./canlii-app), [agent-101](./agent-101), [video-speed-ext](./video-speed-ext), [launch](./launch), [runs](./runs)

Native builds tag `<name>-native-v*` and run through `native-release.yml`. Deploys are by hand with `wrangler`. A push deploys nothing.

## Not in labs

Nimble, Epiphany, Patois, Echo, Joshua Tree, Turing and the rest of the fleet are their own repos. On 2026-10-29 coda, bugle, horula, hamurapi, noema, toroid, journal, numen, costanza and seamark left labs for their own repos, history kept. Cadence, fieldbook, homeqi and dream are next. `CLAUDE.md` has the full map with what each one is.

## Root files

- `CLAUDE.md`: the map of every project, the stack and the house rules
- `roadmap.md`: cross-project queue
- `GTM.md`: revenue ledger
- `SHIPPING.md`: how an app gets from Xcode to the App Store with `asc`
- `README-TEMPLATE.md`: how a project README is written
- `progress.svg`, `fleet.svg`: snapshots, regenerated by `scripts/`
