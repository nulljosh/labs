# Homeqi

Feng shui home assessment condensed from Eva Wong's *Good Fengshui*. Live at homeqi.heyitsmejosh.com. Renamed from fengshui 2026-09-03; the Cloudflare Pages project is still `fengshui`.

- Web is the product. `ios/` is a reader-only wrapper, parked. `watchos/` is a companion
- 24 questions across four layers, each cites the chapter it came from. Keep the book's reasoning attached to every answer
- Uses the Bookrank theme. Deploy with `wrangler pages deploy`
