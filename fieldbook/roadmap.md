# Fieldbook Roadmap

## v1+

- [ ] Mobile-optimized touch interactions (swipe to navigate fields, pinch to zoom graph)
- [ ] ASC submission (needs a name check; weather apps blocked, also need real app store name)
- [ ] i18n support (translate field descriptions across 26 languages)
- [ ] Search ranking and sort options (popularity, alphabetical, by domain)

## Not Building

- Subtopic drill-down (stays one level: field overview only)
- Video tutorials or external links
- Collaborative editing
- User annotations or notes
- Mobile app release to App Store (v0 is web-first, native ports generated for consistency)
