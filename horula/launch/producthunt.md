## First comment

Hi, I'm Josh, I built Horula. The name is Latin for "little hour".

The iPhone Clock app is the best small tool on the phone, and I wanted it on my Mac and on the Windows laptop at work. So Horula is the same set of tools: world clocks with small AM and PM, alarms with snooze and skip next, a bedtime schedule, a stopwatch with an analog dial, timers you can pin, and a nightstand mode that dims and drifts so the screen never burns in.

A few things the iPhone does not do: a world map with the real line between day and night, a slider to find an hour that works across cities, interval timers, and a clock you can drop on any web page with one iframe.

It is one static page with no build step and no server, so it loads once and works offline. The iPhone and Mac app is native SwiftUI, and on iPhone it uses AlarmKit, so alarms ring even when the app is closed or the phone is on silent. Free, no account.

Happy to answer anything.
