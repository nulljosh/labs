## Wednesday

Finished Plain with syntax highlighting, Ollama completions on Mac, a Nimble hero, and error handling. ## Thursday

Set up local models (oMLX), finished Plain's landing page with a live demo, and shipped the native fleet rollout: all 17 apps got real Kotlin ports, swing extracted to its own repo, WCAG audit to zero failures, and an icon color pass across seven apps. The fleet is now 30 apps live across platforms with the cross-platform template proven out.

Spent the evening researching the Nori A3 robot and whether building one is feasible now or needs a robotics degree. Turns out the hardware is approachable: the $199 SO-ARM101 kit is open-source and LeRobot-compatible, so the real value of a degree would be the manipulation software, not hardware. Decided to start with the kit now instead of waiting for school.

## Security sweep

Ran a security sweep and found an IDOR in Epiphany's webhook GET endpoint. The ?action=generate&customerId= query accepted any customer ID without checking ownership, so anyone who guessed a Stripe ID could fetch another user's TradingView webhook key. Fixed it to require a session and verify ownership. Confirmed Epiphany is fully migrated off Vercel onto Cloudflare.
