Built Plain, a plain text editor for iOS and macOS using SwiftUI's DocumentGroup. Single xcodegen target generates both platforms from one codebase. Included a `plain stat` CLI that shares Stats.swift with the native app. Landing page went live at plain.heyitsmejosh.com with Wrangler static assets. iOS got document access via UIFileSharingEnabled and LSSupportsOpeningDocumentsInPlace so users can create and edit files.

Apps: Plain ships iOS and macOS from one target. logans-frenchies pitch ready.

## Wednesday

Finished Plain: syntax highlighting for code and Markdown, command-return on Mac to ask a local Ollama model for completions, and a graphite landing page with a Nimble-style hero. Mac settings live in a plain.json file that opens on first launch. The "Edited" flag that shows right after opening a file turned out to be an iOS 26 TextEditor quirk, not mine, so I noted it and moved on. Added error handling for encodings, bad config values, and completion failures that explain why in the footer, plus an XCTest suite with 25 tests covering stats, colouring, document round-trips, config parsing, and the completion error path. Also wrapped the logans-frenchies pitch site with a navy-and-gold icon and drafted the pricing email to Logan.

## Thursday

Read Kevin Lewis's post on running local models on his Mac mini and copied it, scaled to a third of his memory. Swapped Ollama for oMLX, which is built for Apple chips and noticeably snappier, and pulled a tiny Gemma for quick questions plus a mid-size Qwen for code. The first Qwen was too big and refused to load, so I went a size down. Pointed opencode at it, so the boring stuff is free now and my Claude quota goes to the hard problems. Tailscale for phone access is still on the list.
