Built Plain, a text editor for iOS and macOS sharing one xcodegen target. Included a `plain stat` CLI, landing page with Wrangler assets, and document access for iOS users.

Apps: Plain ships iOS and macOS. logans-frenchies pitch ready. bookrank screenshot-to-summary live.

## Wednesday

Finished Plain: syntax highlighting for code and Markdown, command-return on Mac to ask a local Ollama model for completions, and a graphite landing page with a Nimble-style hero. Mac settings live in plain.json, and the "Edited" flag quirk was iOS 26's TextEditor, not mine. Added error handling for encodings, bad config values, and completion failures that explain why in the footer, plus an XCTest suite with 25 tests covering stats, colouring, document round-trips, config parsing, and the completion error path. Wrapped logans-frenchies with a navy-and-gold icon, drafted the pricing email, and fixed Epiphany's debt tracking when the new Telus bill hit at $228.99 due 2026-09-25 (updated the portfolio from 300 to 220).

## Thursday

Set up local models on the Mac (oMLX with Gemma and Qwen) to free up Claude quota, added screenshot-to-summary to bookrank via Workers AI, and moved Quotestreak's settings into a sheet. Still waiting on Sign In with Apple to unblock iOS shipping. Investigated Epiphany's auto-trading: Wealthsimple's read-only by design, but I unlocked live mode to run the full watchlist with a $50/trade cap and 20-trade limit, pending Alpaca signup.

Finished Plain's landing page with a live demo: replaced the static screenshot with a real textarea, and the page runs the same Stats.swift counting logic in JavaScript as visitors type. Deployed to plain.heyitsmejosh.com.

## Security sweep

Ran a security sweep and found an IDOR in Epiphany's webhook GET endpoint - the ?action=generate&customerId= query accepted any customer ID without checking ownership, so anyone who guessed a Stripe ID could fetch another user's TradingView webhook key. Fixed it to require a session and verify ownership. Also confirmed Epiphany is fully migrated off Vercel onto Cloudflare; vercel.json is a leftover file, wrangler.jsonc and custom domain routing is live.
