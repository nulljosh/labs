Built Plain, a plain text editor for iOS and macOS using SwiftUI's DocumentGroup. Single xcodegen target generates both platforms from one codebase. Included a `plain stat` CLI that shares Stats.swift with the native app. Landing page went live at plain.heyitsmejosh.com with Wrangler static assets. iOS got document access via UIFileSharingEnabled and LSSupportsOpeningDocumentsInPlace so users can create and edit files.

Apps: Plain ships iOS and macOS from one target. logans-frenchies pitch ready.

## Wednesday

Shipped Plain with syntax highlighting for code and Markdown files, plus command-return on Mac to request completions from a local Ollama instance (completions stop at a blank line). The landing page went from yellow to graphite with a Nimble-style animated hero, added spacing and keyboard shortcuts (Cmd+/-/0 for zoom, Cmd+Shift+M for monospaced), and bumped both platforms to iOS 26/macOS 26. Files now save in place, the editor is feature-complete, colour initialization moved from onAppear to EditorView init to fix cursor reset when Mac tabs are reshown, and Mac settings are a plain.json text file that opens on first launch and applies when saved (font size, monospaced toggle, completion model, five syntax colours as hex). Verified the "Edited" title flag appearing right after opening any file is the iOS 26 AttributedString TextEditor inside DocumentGroup, not our code - noted in roadmap as a known cosmetic issue.

Also finished the logans-frenchies client pitch site: added a navy-and-gold frenchie icon to the README and all pages, drafted a pitch email to Logan (Vancouver Frenchies breeder, past customer) with pricing at $2,500 build plus $150 per month hosting or $1,800 flat, and kicked off the favicon deploy to Cloudflare Pages.

## Thursday

Read Kevin Lewis's post about running local models on his Mac mini and figured I could copy most of it, even though mine has a third of his memory. Swapped Ollama for oMLX, which is built for Apple chips and noticeably snappier, and pulled down two models: a tiny Gemma for quick questions and a mid-size Qwen for code. The first Qwen I tried was too big and the server just refused to load it, so I went a size down and it runs fine. Pointed opencode at it, so now I have a free local assistant for the boring stuff and can save my Claude quota for the hard problems. Still need to hook up Tailscale so my phone can reach it.
