Built Plain, a plain text editor for iOS and macOS using SwiftUI's DocumentGroup. Single xcodegen target generates both platforms from one codebase. Included a `plain stat` CLI that shares Stats.swift with the native app. Landing page went live at plain.heyitsmejosh.com with Wrangler static assets. iOS got document access via UIFileSharingEnabled and LSSupportsOpeningDocumentsInPlace so users can create and edit files.

Apps: Plain ships iOS and macOS from one target. logans-frenchies pitch ready.

## Wednesday

Shipped Plain with syntax highlighting for code and Markdown files, plus command-return on Mac to request completions from a local Ollama instance (completions stop at a blank line). The landing page went from yellow to graphite with a Nimble-style animated hero, added spacing and keyboard shortcuts (Cmd+/-/0 for zoom, Cmd+Shift+M for monospaced), and bumped both platforms to iOS 26/macOS 26. Files now save in place, the editor is feature-complete, and colour initialization moved from onAppear to EditorView init to fix cursor and colour reset when Mac tabs are reshown. Verified the "Edited" title flag that appears right after opening any file (including plain .txt) is the iOS 26 AttributedString TextEditor inside DocumentGroup, not our code - noted in roadmap as a known cosmetic issue.

Also finished the logans-frenchies client pitch site: added a navy-and-gold frenchie icon to the README and all pages, drafted a pitch email to Logan (Vancouver Frenchies breeder, past customer) with pricing at $2,500 build plus $150 per month hosting or $1,800 flat, and kicked off the favicon deploy to Cloudflare Pages.
