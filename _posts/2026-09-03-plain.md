Built Plain, a plain text editor for iOS and macOS using SwiftUI's DocumentGroup. Single xcodegen target generates both platforms from one codebase. Included a `plain stat` CLI that shares Stats.swift with the native app. Landing page went live at plain.heyitsmejosh.com with Wrangler static assets. iOS got document access via UIFileSharingEnabled and LSSupportsOpeningDocumentsInPlace so users can create and edit files.

Apps: Plain ships iOS and macOS from one target. logans-frenchies pitch ready. bookrank screenshot-to-summary live. Epiphany debt tracking corrected.

## Wednesday

Finished Plain: syntax highlighting for code and Markdown, command-return on Mac to ask a local Ollama model for completions, and a graphite landing page with a Nimble-style hero. Mac settings live in plain.json, and the "Edited" flag quirk was iOS 26's TextEditor, not mine. Added error handling for encodings, bad config values, and completion failures that explain why in the footer, plus an XCTest suite with 25 tests covering stats, colouring, document round-trips, config parsing, and the completion error path. Wrapped logans-frenchies with a navy-and-gold icon, drafted the pricing email, and fixed Epiphany's debt tracking when the new Telus bill hit at $228.99 due 2026-09-25 (updated the portfolio from 300 to 220).

## Thursday

Set up local models on the Mac: swapped Ollama for oMLX and loaded Gemma plus a mid-size Qwen for code work. First Qwen was too big, so scaled down. Now the trivial stuff is free and my Claude quota goes to hard problems. Also added screenshot-to-summary to bookrank's library editor: snap a photo of a book page, Workers AI reads it and writes the summary, photo discarded after extraction, whole flow auth-gated via Supabase. Live now at bookrank.heyitsmejosh.com.
