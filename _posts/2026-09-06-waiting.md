## Sunday

Wordroot's macOS version hit a 4.3(a) spam rejection while iOS got approved, so filed a reply asking Apple to clarify. Debugged a year-long macOS permission popup in cmux where Claude Code kept asking for Documents folder access on every session: cmux keys TCC grants to the binary's file path, and every Claude update created a new path in ~/.local/share/claude/versions/, throwing away the grant. Fixed it with a fish function that copies the current version to a stable path and runs from there. Consolidated all loose config into dotfiles (fish functions, gitconfig, hooks, zsh, cmux, Claude settings), symlinked back, and extended install.sh.
