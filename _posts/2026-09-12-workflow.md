## Saturday

Added a ship-mac workflow to wordroot's ASC automation setup mirroring ship-ios, then refreshed the README with Mac and iPhone screenshots captured from the live site; wordroot's structure already matches the nimble reference architecture so no code changes were needed. Fixed the journal blog's CI build by having deploy.sh auto-stage and push the generated chart assets before jekyll builds, closing out a recurring frustration. Rethinking conveyer's architecture: the "LLM writes Python each turn" approach hit a wall where small models get stuck re-guessing broken snippets instead of fixing them. Switched to a skill-router pattern instead: a fixed library of deterministic functions (mine, smelt, craft, place, build_power) on top of FLE's primitives, each validating inputs and verifying success against game state before returning. The LLM now just picks a skill name and JSON parameters each turn, mirroring AI Player v3 and turning exploration into actual progress instead of syntax loops.
