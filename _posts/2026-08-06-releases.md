## Thursday (August 6)

Voxprint shipped on the Mac, which is funny given the phone version has been sitting in review since the third. Finished Inkpress's overdue redesign, swapping an icon that had faded to an invisible hairline for something you can actually see, and gave it a real landing page instead of a bare store link.

## Friday (August 7)

Renamed Uprighty to Bookrank after the store rejected the name as a duplicate, cycling through five taken alternatives first. Spent the evening on Epiphany's statement uploads, where the storage bucket had been created public by default and cannot be made private after the fact, so I built a new one and repointed everything at it.

## Saturday (August 8)

Cleared the notes inbox and unstuck two apps that had been sitting in review behind phantom rejections. Two other things that looked like bugs turned out not to be, which is worth noting as often as the real ones.

## Sunday (August 9)

Turned Newsline from a website into something other people's code can call, with a proper API and an agent-facing server, and published it to the registry. Testing it against live feeds surfaced three real bugs, the worst being that the parser only ever understood one of the two common feed formats, so one outlet had been silently contributing nothing since the day I added it.

## Monday (August 10)

Finally got in to read the actual rejection reasons rather than guessing at them. Sparkjar's was simple once visible: the reviewed build hardcoded a hostname that no longer resolves, so every symptom collapsed into one dead lookup. Healstack's demo account had null columns in the auth table, which made the server throw a database error instead of a clean wrong-password. Lesson worth keeping: check a rejection against the actual shipped code and history before trusting the theory already written in the roadmap.

## Apps

Voxprint live on Mac. Bookrank renamed and resubmitted. Newsline now a real API. Audited every app for password recovery, and the one I assumed was worst was the most complete.
