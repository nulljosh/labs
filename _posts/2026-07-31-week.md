## Sunday (August 2)

Finished the colony autoplay fix properly. The patch from the night before had only covered one of three systems quietly assigning jobs on their own. Cleared Sparkjar's stuck review by cancelling the stale submission and filing a fresh one against the build that was already valid.

## Monday (August 3)

Found Epiphany's payment key had been mangled in an old debugging session, so the webhook had been failing silently ever since. Fixed it and swapped the monthly subscription for a one dollar unlock, then rolled the same idea into three more apps. Submitted four apps for review and caught each one still shipping under its old name minutes before hitting send.

## Tuesday (August 4)

The worst find of the week. Sparkjar's anon key, which ships inside every web and phone client, could read the whole users table, password hashes and reset tokens included. Fixed the permissions, deploying the code before the migration so existing accounts were not wiped on the way through. Underneath it all, the reason logins had been failing was a single mistyped property name that quietly sent every account to temporary storage.

Also swept every app for hardcoded old domain names and found seven pointing at hosts that no longer resolve, which the search almost missed because the codebase is itself a repo and quietly ignores its children.

## Wednesday (August 5)

Moved Epiphany's statement uploads off the key store and onto proper blob storage, and gave the desktop app the upload screen the phone already had. Took the icon back from lime green to the system blue.

## Thursday (August 6)

Chased three separate complaints, about fonts, icons, and sync, back to one cause: a deploy step that silently never ran. Lexly had been serving a two week old build the whole time because it was never wired to git.

## Apps

Epiphany, Healstack, Sparkjar and Talli all got payment unlocks. Curvely, Voxprint, Wiretext and Uprighty submitted. Inkpress got a readable icon and a real landing page.
