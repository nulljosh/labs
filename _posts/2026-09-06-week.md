Completed breathe in one day too: custom pattern builder, rep counter, sound cues, deployed to breathe.heyitsmejosh.com. Fixed Epiphany's debt tracker after the Telus bill.

Set up Ollama, shipped native fleet rollout: all 17 apps got real Kotlin ports, swing extracted, WCAG clean, icon pass across seven apps. Fleet is 30 apps live across platforms. Fixed wordroot's style leaking from chemistry templates and stuck theme-color. Started slicehack, updated portfolio, and found and fixed an IDOR in Epiphany's webhook endpoint.

## Friday

Refreshed the Duolingo bot with a new icon. Looked at the solver script (21K lines) but decided a trim was too risky, so filed it as roadmap work instead. Dug into Epiphany's broken macOS build; old gitignored artifacts were causing "Multiple commands produce" errors, and deleting them fixed the tab bar and screenshots. Fixed a production bug too: Overpass API mirrors were rejecting requests without a User-Agent header, so swapped in working mirrors.

Local model setup for opencode: fixed an oMLX hang, switched from Qwen to llama3.1 for a better tool-call format, and built a skill to delegate repo chores to models. It synced keywords, descriptions, and version drift across the codebase, caught a couple false positives corrected by hand, and fixed a real bug in sidewise (outlet count had drifted to 17 when the feed count is 16), plus the same bug in roost (README claimed 26 languages, actual translation file is 25).

Shipped two Talli features: a directory of free and low-cost BC legal aid organizations, searchable by category and linked from the landing page, plus local notifications for payday reminders and the RDSP contribution window. Caught a date-math bug in the test suite before shipping.

Switched the Duolingo bot to Chess after finishing Math, solving three puzzles from the "Anastasia's mate" lesson. The blocker: the chess board lives in a cross-origin iframe that JavaScript can't read or write, so unlike the math widgets in the same DOM, chess needs manual play (screenshot, click piece, click destination), and intermittent registration bugs forced restarts. Paused until the weekend.
