## Saturday

Pushed v56 through v72 this evening (17 versions in one loop): built Mail, Contacts, Calculator; added day/night wallpaper and weather particles; wired real IP geolocation so it stops lying about Vancouver. Caught three user-facing bugs nobody guessed going in: the notification panel's "wrong font" was the cursor antialiasing text underneath; the dock hover stuck-magnify was two stacked issues (starved page-table cap plus a hit-test off by half a tile since v15); the weather had been asking about the wrong city the whole time. Also found the rtl8139 driver had run one packet behind since v7, hidden for sixty versions until weather made two consecutive requests. Added a real syscall gate, ring-3 task teardown, VMware absolute-mouse, documentation to 100%, and a CI workflow that runs on every push; honest about scope: Epiphany needs TLS, plain-HTTP stock APIs don't exist, multi-window is four steps deliberately deferred.

Investigated multi-window stacking but the kernel doesn't actually support it, so correctly refused to fake it in JavaScript. Captured Joshua Tree's monetization thesis in a new skill: free OS, hardware monetization, native LLM-integrated apps.
