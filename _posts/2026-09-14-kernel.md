Spent the overnight pushing Joshua Tree forward with real semver. Built a live Terminal inside the GUI that captures output, an Apps folder with an 8-icon dock and a Trash you can restore from, and proper per-task memory isolation with SIGKILL. The filesystem layer got real: fat16 + ramfs backends, block devices (ata, ramdisk), and a VFS that lets the file browser actually work. Jumped the GUI to 1920x1080 (960x540 logical, drawn at 2x) and rewrote every string in antialiased DejaVu Sans Mono instead of the bitmap font. The menubar now fetches live Vancouver weather from Open-Meteo over plain HTTP, and the tree actually sways in the wind (8 fps, toggleable, off in the browser demo). Fixed the mobile tap-to-click by homing the cursor to a corner and pacing PS/2 packets; tested it with a real iPhone to verify it works. The browser demo now auto-tours itself when idle. Found and squashed some serious bugs: the demo had no font at all, rounded corners were drawn from the wrong centre, and the wind was erasing the cursor four times a second. Changed the license to Apache 2.0, rewrote the whitepaper, and gave the landing page real content: the 5 Ws section, a footer, proper links. It deploys via wrangler now. Next up is user accounts with admin/standard levels, per-app menus, and wiring Claude/Codex usage into the menubar via a host proxy.
