## Sunday

Spent the night building a kernel from actual nothing. No macOS, no Linux underneath, just me and Claude going through interrupts, memory paging, task switching, a disk driver, a real filesystem, and a text-mode file browser one piece at a time, verifying each part against real disk images instead of just trusting that it compiled. Went through a few names before landing on Joshua Tree, which fits since the whole point is surviving on almost nothing while building something real, fixed a broken live demo on the landing page by swapping it for an actual recorded boot instead of faking it, and cleared up some naming confusion with the older Gato voice project, which stays its own separate thing. Also picked back up Conveyer's Factorio automation, expanding its skill library and getting an unattended bootstrap run working end to end.
