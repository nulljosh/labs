## Wednesday

Built a Twilio secretary bot as a Cloudflare Worker and made the Pwnlingo landing page show a live demo instead of screenshots, with all three puzzle types cycling through. Fixed a race condition in the chess solver and double-counting bug, plus added a settings toggle for always-on-top. Then I discovered the Pages project had no git integration, so I wired up GitHub Actions with a scoped Cloudflare token to auto-deploy on pushes to the web folder. Later did an a11y pass on the landing: hid the decorative demo elements from screen readers and added visible focus rings to all links, then added clickable track buttons so users can pin a puzzle type instead of just auto-cycling. Wordroot got approved for distribution, and ran a fleet-wide lint pass to clean up junk files (11 stray `.DS_Store`, one `.bak`, and several zero-byte tracked files), updating the lint skill to catch these automatically.

## Apps

Pwnlingo landing page now shows a live interactive demo with clickable track buttons to pin Chess, Math, or Language puzzles, or watch them auto-cycle. CI auto-deploy is wired up via GitHub Actions, so pushes to `web/` now auto-deploy to Cloudflare Pages. Wordroot iOS approved for distribution.
