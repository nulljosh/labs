## Wednesday

Debugged Voxprint's model downloads taking forever even for tiny models - turned out WhisperKit wasn't using a background URLSession, so backgrounding the app mid-download would restart from zero. Fixed it by enabling the background session flag and animated the newest live transcription word popping in with a spring, keeping the rest of the transcript static. Built a Twilio secretary bot as a Cloudflare Worker. Reworked Pwnlingo's landing to show live demo instead of screenshots and fixed a race condition in the chess solver. Converted Homeqi into a multi-property assessment tool with independent saved assessments per place.

## Chess debugged

Pwnlingo's solver got stuck in an infinite loop: pawn-promotion picker always clicked the queen's slot, failing underpromotion puzzles. Built a self-calibrating picker that learns each piece's slot from correct grades. Moved solver code from dotfiles to its own GitHub repo checkout, synced both, committed.
