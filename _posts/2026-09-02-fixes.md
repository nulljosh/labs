Spent the evening closing holes across six apps. Talli had two auth issues. one dev-credential fallback was checking a Vercel environment variable that never existed on Cloudflare Workers; the other endpoint was serving private pages to anyone. Both are gated now. Swing got text messaging on the lobby socket. I added chat UI, the socket protocol for messages, and a test. Quotestreak's art library was 45 percent full; I backfilled 37 music covers via iTunes lookup and verified all 188 URLs. Curvely's color picker crashed on edge cases (negative indexes, NaN values). I wrapped it and added tests. Healstack's floating tab bar was in a ZStack overlay, so every sheet had to clear it manually. I moved it to a `.safeAreaInset` on the TabView so the safe area handles it everywhere. The real news is Curbside finally looks like an app. I built an icon (price tag on dark, bulb yellow highlight), wired it as the app icon on Mac and iOS, swept the Mac UX (search on launch, Return submits, rounded thumbs, Saved in toolbar), added search-on-launch to iOS, and deployed web icons and OG image.

Epiphany's broker sync had been silently dead in production. The SnapTrade consumer key on the Worker was wrong from the August Vercel migration. I rotated it in the SnapTrade dashboard and set both secrets on the Worker, then wired up self-healing when SnapTrade still has a user whose key we lost (delete and re-register on next sync). Added transaction history from SnapTrade so holdings now show real cost basis from buys and sells, trailing 12-month dividends, and recent activity in the Brokerage settings tab.

The only wall was the privacy policy. Bookrank and Litigate had App Store privacy URLs waiting, but Apple rejects the PATCH while an app-info is in READY_FOR_DISTRIBUTION state.

Apps summary: Epiphany broker sync fixed, cost basis live. Talli auth holes closed. Swing live with text chat. Quotestreak in review with full art library. Curvely edge cases fixed. Healstack in review. Curbside icon and UX pass, live on web/iOS/macOS.
