## Saturday (July 25)

Ran a polishing pass across six apps: cleaned Epiphany's landing page, fixed Healstack's navbar overlap and display name, tightened Lexly's subject navigation, moved Talli's personal fields into Settings with keychain persistence, redesigned Quotable's icon, and fixed footer contrast on BCGD. Discovered the portfolio had been serving stale builds for days because the apex DNS record pointed at an old Cloudflare project while GitHub Pages was actually hosting the real build. Fixed the record and cleared 18 GB of Xcode artifacts.

## Sunday-Monday (July 26-27)

Journal posts had been silently stalling after commits because the deploy step was never wired into the commit flow. Fixed it so deploys run automatically going forward. Closed an NYC colonist bug where units were looping back into gather jobs immediately after finishing, instead of going idle.

Ran a full icon color pass: Litigate, Lexly, Epiphany, Talli, and Echo each went from near-black monochrome to a distinct brand color. Stripped Google Fonts from four apps and pages load instantly now. Fixed Epiphany's flight panel, which had been treating a radius as a full span and doubling the search area on both iOS and Mac.

## Tuesday-Wednesday (July 28-29)

Found and closed a serious security hole in Litigate: case documents were embedded in plain HTML behind a CSS overlay and readable without any login. Moved the data into Supabase with row-level security, emptied the HTML, and verified both hostnames return nothing before authentication.

Uprighty went live on the App Store with all four book summaries complete. Echo got renamed to Voxprint after the App Store rejected the single-word title as already taken, and Grapher became Curvely to match its existing listing. Ran a git hygiene sweep across seventeen repos, pushing six deferred commits and filing roadmap notes.

## Apps

Uprighty 1.0 live. Talli 3.5.12, Lexly iOS 1.1.3, Lexly macOS 1.1.1, Sparkjar Mac 1.0 submitted for review. Voxprint 1.3.6 drafted. Litigate security patched and live. Five app icons redesigned with brand colors.
