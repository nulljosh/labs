Refreshed the Duolingo bot with a new icon. Looked at the solver script (21K lines) but decided a trim was too risky, so filed it as roadmap work instead.

Dug into Epiphany's broken macOS build. Old gitignored artifacts were causing "Multiple commands produce" errors; deleting them fixed the tab bar. The same garbage was breaking screenshots. Fixed a production bug too: Overpass API mirrors were rejecting requests without a User-Agent header, so swapped in working mirrors.

Local model setup for opencode: fixed an oMLX hang, switched from Qwen to llama3.1 (better tool-call format), and built a skill to delegate repo chores to models. It synced keywords, descriptions, and version drift across the codebase, caught a couple false positives (corrected by hand), and fixed a real bug in sidewise (outlet count had drifted to 17 when the feed count is 16). Found the same bug in roost (README claimed 26 languages, actual translation file is 25).

Shipped two Talli features. Built a directory of free and low-cost BC legal aid organizations (Legal Aid BC, CLAS, Disability Alliance BC, and others), searchable by category and linked from the landing page. Also added local notifications for payday reminders and when the RDSP contribution window opens. Caught a date-math bug in the test suite before shipping.

Switched the Duolingo bot to Chess after finishing Math. Solved three puzzles from "Anastasia's mate" lesson. The blocker: the chess board lives in a cross-origin iframe that JavaScript can't read or write. Unlike math widgets in the same DOM (which script unattended), chess requires manual play: screenshot, click piece, click destination. Got intermittent registration bugs (moves failed silently, forcing restarts). Pausing until this weekend.
