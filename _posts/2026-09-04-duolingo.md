Refreshed the Duolingo bot. Gave the owl mascot a tongue sticking out in the icon. Then looked into whether the solver script could be trimmed down. It's about 21K lines, mostly 76 fallback cases for different question types, and the cases have subtle interdependencies. Flattening seemed too risky, so I decided to leave it alone and file it as a roadmap note instead.

Also dug into why Epiphany's macOS build had been broken for a while. Turns out old build artifacts (the app bundle, package, and dSYM) were sitting in the source tree gitignored and causing "Multiple commands produce" errors. Deleted them, rebuilt, and suddenly the app's tab bar and window rendered correctly again. Found the same issue was silently breaking the screenshot pipeline, which is why the README's macOS screenshot was three weeks stale. Also fixed a production map bug: the Overpass API mirrors were rejecting our Worker's requests with 403/406/521 because we weren't sending a User-Agent header, so the Situation map's incidents layer was degraded. Swapped two dead mirrors for working ones and added the header, and now it returns real data. Small test-suite fix too, just an initializer that was missing.

Apps: Plain ships iOS and macOS (web landing live). breathe live (web MVP). bookrank with screenshot-to-summary. All fleet apps on real Kotlin ports now.
