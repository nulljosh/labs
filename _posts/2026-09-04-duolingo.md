Refreshed the Duolingo bot with a new icon. Looked at the solver script (21K lines, subtle interdependencies) but decided a trim was too risky, so filed it as roadmap work instead.

Built a chess autopilot for lichess puzzle training. Lichess ships puzzle solutions to the browser in plain text, so the solver just replays the moves as chessground mouse events. Wired it up the same way as the Duolingo solver: extension auto-injects on lichess.org/training, chessBoot.js posts state to serve.py, and test_chess.mjs validates the core logic offline. Fixed a few gaps today (orientation detection now fails loudly instead of guessing white, added heartbeat monitoring) but haven't tested it against a live tab yet.

Dug into Epiphany's broken macOS build. Old gitignored artifacts were causing "Multiple commands produce" errors; deleted them and the tab bar rendered again. The same garbage was breaking the screenshot pipeline (README screenshot had drifted stale). Fixed a production map bug too: Overpass API mirrors were rejecting requests without a User-Agent header, so swapped in working mirrors and added the header.

Local model setup for opencode: fixed an oMLX streaming hang, discovered Qwen models emit broken tool-call format, switched to llama3.1 (correct format), uninstalled a 7GB unused model. Built a skill (renamed cheap-fix) to delegate repo chores to local models and used it across most of the codebase: added missing package descriptions, synced keywords and GitHub repo descriptions, fixed version drift, patched gitignore gaps. It caught two hallucinated outputs and a couple of false-positive gitignore checks along the way; corrected those by hand before committing. Also let it fix a real bug: sidewise's outlet count had drifted to 17 across four files while the actual feed count is 16, llama rewrote each stale line correctly. Found the same bug pattern in roost, its README claimed 26 languages when the actual translation file has 25, fixed that one by hand.

Apps: Plain ships iOS and macOS (web landing live). breathe live (web MVP). bookrank with screenshot-to-summary. All fleet apps on real Kotlin ports now.
