## October 2

Pushing the Joshua Tree release hard. PR #331 shipped all fixes yesterday (parser-fuzz stub added, ceiling tightened, window budget capped, demo slowed to match real hardware); CI verdict still pending but locally green headless. The one failing check grabbed a screenshot 0.3s into the window drag before CI's slow runner repainted Notes, so I added polling for the mid-drag frame with a 2-second timeout. If it passes on GitHub, I merge and tag the release tonight. PR #336 needs kernel.c trimmed by 4 lines (it's at 9359, ceiling 9355) plus a Bookrank ring-3 fix. PR #337 rebases after main. Bookrank iOS went live with natural ElevenLabs voices and all the features built over the week; rotated a leaked ElevenLabs key today and swapped in the new bookrank-voices key (Starter tier, 31K chars/month) with per-chapter model selection (v2 multilingual for chapter one, flash for the rest) and two host voices. Live QA passed: speak endpoint green for both hosts and both chapter models, KV cache working, auth properly gated (401 without token, 400 on empty text, 405 on GET), long text trimmed, all test suites green. Trend 2x rules went live on the Autopilot and menu bar. Both are shipping user-facing right now.

Evening session caught a pixely Launchpad dock icon for Joshua Tree; the Mac launcher had been booting a stale local checkout stuck on a Sep 27 kernel branch. Reset to origin/main, rebuilt, and the icon was sharp again. That unblocked PR #336: the kernel.c god-file check was hitting because the file had grown 4 lines over its ceiling, plus Bookrank's ring-3 text was getting sampled by the old render pipeline in the middle of a glyph load. Tightened kernel.c, pulled in a Bookrank render fix, and got 11 of 12 checks green with auto-merge armed. PR #339 landed Samantha's dock icon as her own mark from the Turing repo, profile crop, checks passing locally. Next: per-app data sync so Bookrank and other ring-3 copies can pull real app data at build time instead of hand-coded placeholder content.
