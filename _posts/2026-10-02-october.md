## Oct 6

The Raspberry Pi 4 arrived and Joshua Tree booted on real hardware for the first time. Half-size display with console text shattered into one-pixel marks; the CPU cache wasn't flushing to RAM. By evening it was fixed: full 1920x1080, readable console, and a Steve Jobs line above the dock that ends "Make something wonderful," from the Steve Jobs Archive book I'm reading. USB controller written in QEMU first, then on the Pi itself; a NuPhy keyboard enumerated and keys printed instantly once I swapped the charge-only cable for a real data cable. A Wi-Fi driver is written and waiting on tests; I started a Claude app for Joshua Tree that talks through a relay on the Mac, so Claude Code can eventually run inside my own OS on the Pi and help build it. The roadmap hit 70 items listing what Linux has that we don't: admin accounts, a shell, internet, a browser, x86-64 PCs. I wrote a shopping list for Pi parts and books to read next, locked seven standing decisions (Claude opens pull requests but never merges; 3.0 means I can type and click on the real Pi; the OS stays free), and found that running test suites together made them trip over each other, so they now run one at a time. tools/flash-pi.sh flashes a card without Raspberry Pi OS; MONEY.md lists Pi as the first real dev kit. Merged three PRs into main: Claude relay, USB hot-plug, Pi log. Keyboard types on real Pi. Wi-Fi flashed and running; code scrolls off so building Page Up. Pruned roadmap to top 10 in docs/roadmap-done.md; five research rounds (Circle/Onyx, Pi/RISC OS, macOS/Windows, SerenityOS/Haiku, Android/Chrome) cover Linux gaps, x86-64 slices, admin/sudo, MBR/FAT32 from YouTube. Cleaned repo: 8 worktrees and 6 branches removed, zero issues. Open: PR 435 (Wi-Fi), 436 (tribute/shopping), 437 (crash), 438 (scrollback), plus internet-stack helper.
