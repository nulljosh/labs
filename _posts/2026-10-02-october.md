## Oct 6

The Raspberry Pi 4 arrived and booted Joshua Tree to a full 1920x1080 desktop by evening (the CPU cache flush was the fix). I wrote the USB driver in QEMU first, and a keyboard typed on the Pi the moment I swapped cables. A Claude relay lets my Mac help build the OS from inside it. The roadmap got pruned to ten items after research on what Linux and macOS have that we don't.

## Oct 7

The Pi boots to a full 1920x1080 desktop with a dock of eleven icons, window frames and a working USB keyboard. It plays a one-lap dock demo on its own, since there is no mouse yet. Then the big one: the Pi joined Wi-Fi on the real board. The chip has no login helper, so I wrote the WPA2 handshake myself and checked it against the spec and a capture from a real router. The long stall was one detail. The router wanted a block of association data repeated exactly, and once that matched, the Pi joined the home network with its keys installed. Bring-up is at 9 of 10 steps and stuck on getting an address. Wi-Fi status now sits in the menu bar, and the boot console prints one line per result. The Wi-Fi name and key only go on dev cards, so release builds carry no network. The clock still reads --:-- with no time source. Reading failure lines off photos found the real bugs, from a frozen core to chip RAM 32 KB short and guessed addresses. Pulling the SD card mid-flash froze my Mac's disk until reboot. I drew a scribble Joshua tree logo in marker after seven rounds, and eight fonts went into the kernel registry. The architecture diagram is now one graph of the whole project, the north star got written down (a computer that knows what I want before I ask), and the README logo shipped as its own tiny change. The open work is one draft pull request. CI has to rerun on it before it goes ready, and the benchmark waits for that run. Next: the clock, per-app menu bars, speaker, browser, a Bluetooth mouse, phone, then the Yeti mic. The OS stays free; money comes from a Pi dev kit with a waitlist already live. Weekly Claude usage is at 92 to 94 percent, so big features wait for the Saturday reset. After ten rounds of naming candidates, Joshua Tree stays.
