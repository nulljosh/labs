## Tuesday

Built and shipped Co-Stanza, a poetry network shaped like Svbtle: one column, your name, your poems, nothing else. It's live at co-stanza.heyitsmejosh.com with iOS, macOS and Kotlin ports all talking to a shared Supabase project through row-level security. Sign in, register, forgot and reset password work everywhere, and I added an authmail theme for Co-Stanza. Cleaned up the voxprint repo too: dropped the dead web PWA, removed unused ExportOptions plists, and trimmed the git history, shrinking it from 1.5 GB to 518 MB.

## Wednesday

Got Paid Apps Agreement approved, so shipped Voxprint with a $1 paywall and NYC Survive with fixed icons, both declaring exempt encryption. Built Epiphany's Premium tier via StoreKit 2, server-verified via App Store Server API, and submitted it. Built a `/launch` skill that generates Product Hunt kits and ran it across 12 apps, adding badge.py and a --ph-url flag to stamp branding into readmes and landing pages. Voxprint's Product Hunt post is scheduled to go live Sep 10, with landing page and readme badge already live; the other 11 apps' kits are staged for when usage resets.
