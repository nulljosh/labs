## Sunday

Ripped Google Fonts out of Echo, Spine, Sparkjar and Talli and went back to whatever font the machine already has. Pages feel instant now, and I keep wondering why I ever paid a round trip for something the OS ships for free. Along the way I found out Echo's landing page isn't on Vercel at all, it's on Cloudflare Pages with no auto-deploy, so every push needs a manual wrangler command. That explained a few "why didn't my change go live" moments.

Also went back and fixed two Epiphany bugs I'd been ignoring. The Flights panel had never worked, and it turned out to be a units mistake: a radius being treated as a full span, so every request asked for twice the area the API allows. Same mistake in the iOS and Mac clients. The saved statements error was a loop, a callback getting rebuilt on every change and refetching forever. Both fixed. Put the People tab and Daily Brief behind Pro too, since they'd been quietly free.

Small stuff: Spine has a To Read list now, Talli's icon is blue and 3.5.11 is off to review, and I finally got the blue circle off my portfolio avatar by flood-filling from the border instead of color-keying, which kept the eyes intact.

## Monday

Tackled BCGD's booking form, which had been throwing away every lead it received. Built a real database pipeline and added service/area pages so the site is now an actual site, not a page pretending to be one. Then I went to open-source the litigation app and found something much worse: the live site was serving real court documents to unauthenticated users. Logged it as the top priority and stopped.

Fixed Lexly's app icon too—the old one was outline strokes that were invisible at any size, so I redesigned it to a solid white speech bubble with blue dots for legibility. Also stripped out the serif display font and Google Fonts links that made the landing page look decorative. Screenshots were stale (still showing the pre-rename "Lingo" title), so I re-shot them and created a new iOS v1.1.3 to hold the corrected assets. macOS v1.1.1 screenshot also fixed. Came back and built both: Lexly iOS v1.1.3 with the new icon submitted for review (build 202607271632), and macOS v1.1.1 resubmitted (same icon and fonts, had to cancel the old rejected submission first). SwiftLint wiring in the project failed on the first archive with a plugin-validation error — yanked it from the config and rebuilt cleanly.

Also fixed the bigger one: closed the Litigate leak. The site had been serving case documents unauthenticated because the auth overlay was CSS-only. Added a fail-closed Pages Function that gates everything with Basic Auth (`web/functions/_middleware.js`), so now litigate.heyitsmejosh.com and litigate.pages.dev both return 401 pre-auth and 200 post-auth. Root cause was that the Pages project is direct-upload (never connected to git), so pushes did nothing — had to use wrangler's OAuth token instead (`npx wrangler pages deploy`). Still need to rotate the token (it got logged) and audit old deployment URLs, but the live hostnames are now locked.

Later added Newsline and Etyma as standalone entries in the portfolio's work section, and linked a Labs source to highlight the 5 undocumented subprojects that had graduated to their own repos (bank, braingraph, code-meta, video-speed-ext, abraham).

Also crystallized the school plan: SFU Computer Science with a Beedie Finance minor, with an optional MSc track after a couple years working. Moved it from a loose file in Downloads into a tracked project with proper README and roadmap—feels good to have that decision encoded somewhere I can actually keep iterating on it.

Wrapped the night by refreshing Epiphany's README: badges are now clickable links instead of just images, fixed the macOS version range and license metadata, added a fourth screenshot, and condensed the roadmap to Now/Next priorities. Pushed a prod build that had been sitting 6 days stale on Vercel.

Split the plan into two repositories: the original private repo holds the full unredacted roadmap (transcript grades, disability funding, income constraints, and full references), while a new public mirror at heyitsmejosh.com/plan-site strips those sections and serves on GitHub Pages. Documented the redaction procedure in plan/CLAUDE.md so the public version can be rebuilt whenever the plan changes.

Also built a dispute packet for Jayda—merged a parking ticket photo and PayByPhone receipt with a written summary and call script into one 4-page PDF. The parking was paid during the session, but the online dispute window expired, so the only path forward is a phone call to 604-257-8732.

## Tuesday

Found life.heyitsmejosh.com was ranking on the first page of Google for my name. It's a personal timeline page with sensitive content I wrote during therapy—living in my car, an arrest—that should never have been public. It had been deployed to Cloudflare Pages and lingered there after I stopped working on it. Backed up the live HTML locally, then deleted the custom domain and the entire Pages project via the Cloudflare API. It now 522s and should drop out of Google search results in a few days. Still need to clean up a stale DNS record and optionally request removal from Google Search Console.

Also finished syncing book summaries into Spine. Added complete summaries for both IBS For Dummies (chapters 16–23) and Sobriety For Dummies (intro through chapter 11), bundled them into the iOS app with badges, and added a privacy policy page to the site.

Wrapped the evening by continuing book summaries from iCloud photos. Added Sobriety chapters 16–17, logged three stray image files that were book covers only, and updated the roadmap. Mid-flow I tried dispatching six cold subagents in parallel to speed things up, which backfired: usage rocketed from 47% to 93% in about ten minutes and four of the agents got killed before writing anything. Learned the hard way to dispatch one at a time and check usage between each.

Properly sealed Litigate's security leak. The case documents were hardcoded in HTML so a CSS overlay couldn't protect them. Moved them to Supabase with row-level security, emptied the HTML, and fetch and inject on login—live sites now return content only to authenticated users.
