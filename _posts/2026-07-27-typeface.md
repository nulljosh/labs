## Sunday

Simplified Echo's web frontend tonight—replaced the external Google Fonts dependency with the system font stack and pulled the italic styling from the headers. Faster rendering, smaller bundle, one less third-party resource to worry about. After pushing the commit, discovered the landing page isn't hosted on Vercel like most other projects—it lives on Cloudflare Pages with no git auto-deploy, so the deployment requires a manual `npx wrangler pages deploy web/ --project-name=echo` step after every push.

Spent the rest of the evening doing a font audit across the web tier—Spine, Sparkjar, and Epiphany all had external typeface dependencies I could rip out. Replaced Google Fonts and Fraunces with the system stack (Geist for body text, SF Pro / Helvetica for display), streamlined italic styling, and committed the changes across all four projects. One theme: third-party font loading adds latency, bundle size, and runtime complexity for something the browser's system fonts already do better. Updated the wiki and journal with the changes.
