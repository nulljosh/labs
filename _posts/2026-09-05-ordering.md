Updated the portfolio's work list ordering rule. The ranking had been by platform breadth (4 platforms, then 3, then 2, then 1, then source-only), but that doesn't reflect the real state anymore. Changed it to rank by App Store submission status instead: submitted/live on the App Store first, everything else after (Labs still last). No code change needed, the index already matched the new sorting principle.

Gave nimble a terminal window. Added a SwiftTUI pilot, a separate binary target that reuses the existing query engine but renders answers as a bordered terminal card instead of the web UI. Pulled QueryResult out into its own file to avoid a naming collision with SwiftUI's View type, then wired up the new tui target. The binary runs from the command line and needs a real terminal (SwiftTUI reads the window size with ioctl), which is expected. This is step one of a fleet-wide plan to give every app a command-line interface; nimble's the pilot, but curvely, numen, wordroot and the others are still open.

Apps: Plain ships iOS and macOS. breathe live (web MVP). bookrank with screenshot-to-summary. Talli with local notifications and legal aid directory. All fleet apps on real Kotlin ports.
