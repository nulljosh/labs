Updated the portfolio's work list ordering rule. The ranking had been by platform breadth (4 platforms, then 3, then 2, then 1, then source-only), but that doesn't reflect the real state anymore. Changed it to rank by App Store submission status instead: submitted/live on the App Store first, everything else after (Labs still last). No code change needed, the index already matched the new sorting principle.

Gave every stateless app in the fleet a terminal window. Started with nimble as a pilot, then rolled out SwiftTUI to sixteen apps total: nimble, cadence, numen, wordroot, keyrate, curvely, charwork, bookrank, quotestreak, inkpress, tripwire, sidewise, nyc, curbside, homeward, roost. Each app got a tui/ folder plus a root Package.swift (new SwiftPM target depending on rensbreur/SwiftTUI). The pattern reuses what exists: most apps pull their logic from a Foundation-only model file (QueryEngine in nimble, Parser in numen), or fetch from their own API when logic is server-side, or call a public API (Nominatim for roost, Supabase for homeward). keyrate ported its score.js math line-for-line; nyc pulled its building-cost lookup. All terminals are one-shot renders and need a real TTY to run (SwiftTUI uses ioctl). Deliberately skipped epiphany, talli, litigate, sparkjar, healstack, lexly (personal/financial/legal data gates), voxprint (mic input), seamark and homeqi (watchOS only), bcgd (local data), dream (safety-sensitive distress endpoint), swing (repo empty locally), plain (prior choice against terminal editor). Updated all sixteen READMEs with Terminal usage docs. Also fixed ~/.claude/hooks/usage-context.sh which was reading the ccusage fake projection instead of real OAuth usage, causing false low-quota warnings. All sixteen apps committed and pushed individually.

Interactive device-frame demos landed on charwork and numen's landing pages (UA-sniffed iPhone 15 frame with live engines embedded). Charwork shows the wireframe lookup tool; numen shows the calculator. Both deployed via wrangler.

Apps: Plain ships iOS and macOS. breathe live (web MVP). bookrank with screenshot-to-summary. Talli with local notifications and legal aid directory. All fleet apps on real Kotlin ports.
