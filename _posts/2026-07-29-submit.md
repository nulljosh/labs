## Friday

Evening update: restyled Nimble's landing page to match Maybulb's design system—pulled the live CSS from maybulb.com and rebuilt the docs/index.html to use their yellow (#ffca30) section dividers, flat square buttons, Avenir Next font, and black text on white. ## Saturday

Late night rebuild work on localization. Rewrote Talli's i18n/strings.json master (keys now match the literal UI text across Home/Reports/Benefits/Messages/Settings tabs — the old keys referenced a removed pwd/rdsp/cdb feature set and were dropped entirely). Regenerated the iOS string catalog and web locale files via scripts/i18n-gen.mjs, then fixed two real localization bypasses in Swift where ContentView ternary text and BenefitsView benefitRow strings weren't wrapped in LocalizedStringKey(). Built and verified clean. Retrofitted five static JSX labels in web/unified.html to call window.I18N.t() instead of hardcoded strings (React re-render on language switch still remains a gap, flagged in the source comment). Committed and pushed.

Built a brand-new i18n pipeline for Quotable from scratch — it had no localization at all before. Created i18n/strings.json with UI and game strings (score/streak/feedback/final-score), scripts/i18n-gen.mjs generator, and vanilla i18n.js runtime with data-i18n attributes and t() calls. Wired index.html static labels and game.js dynamic strings. Since Quotable's iOS and macOS apps are WKWebView wrappers around the web bundle, synced the i18n files into both Resources folders per the repo's existing sync convention. Verified via node --check and JSON validation (not visually tested in browser). Committed and pushed.

Created a new reusable skill: ~/.claude/skills/localization-sweep/ — audit.sh greps all repos for i18n master files and checks whether web/iOS code actually calls into them (vs. catalog existing but unwired). Flags projects with no i18n at all. This isn't app work — just infrastructure for future audits.
