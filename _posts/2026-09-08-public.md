## Duolingo

The breakthrough came through the React fiber. Correct moves sit in the puzzle state; no board scanning, just memory reads and clicks. Solved 27 chess puzzles, all correct. The language solver reads answer pairs the same way. Bundled js-chess-engine for the match node, found the live FEN in a useRef, and beat the bot in game 1, unlocking the next league rank. Improved the engine with Lasker's principle: when you see a good move, ask one level deeper, and take the deeper answer if it disagrees.

Ported the chess work into Seamark, a chart library on npm. Extracted coordinate logic and DOM traversal as reusable modules, added 18 tests, published on npm. Deployed the solver landing page to Cloudflare Pages at pwnlingo.heyitsmejosh.com with updated README on chess, language, and gaps.
