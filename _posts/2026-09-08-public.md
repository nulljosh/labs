## Duolingo

The Duolingo bot breakthrough came through the React fiber. The correct moves are sitting in the puzzle state as `correctMoves`. No board scanning needed, just memory reads and real clicks on the Rive canvas. Solved 27 chess puzzles across three lessons, all correct. The language solver works the same way, reading answer pairs off the fiber. Bundled js-chess-engine into the solver to handle the match node, found the live FEN in a React useRef six fibers above the board canvas, and beat the bot in game 1 in 19 moves, clearing the whole "beat me 7 times" section and unlocking the next league rank.

Ported the chess work into Seamark, a chart-reading library now in npm. Extracted gridCell coordinate logic and fiberFind DOM traversal from the Duolingo solver as two reusable modules, added 18 passing unit tests, and bumped the version. Pushed to GitHub and published on npm after Joshua ran npm login.
