## Monday (2026-08-31)

Brought Quotestreak's iOS and macOS apps up to parity with the web game and sent both to review, rewrote the portfolio homepage to lead with the Talli story, wrapped API and MCP endpoints on five more apps, and refreshed App Store screenshots for Curvely and Charwork. Spent the evening on reverse-engineering: Freshslice is a white-label of Snappy with an API at gosnappy.io/v1/ that has no auth (just header-based multitenancy, a clear IDOR surface), so I built a Python client to verify the live data. Also looked into Erdős problems as potential computation targets.

## Tuesday (2026-09-01)

Cleaned up the Duolingo skill SKILL.md, which had grown into a lab notebook with self-contradicting sections; trimmed it from 764 lines down to 302 lines of actual instructions. Also discovered Duolingo's course switching is fully solved via a single API PATCH to the user's currentCourseId (the skill notes had three failed UI attempts, but the backend exists). Documented that only one course can be active at a time server-side, so multiple Chrome tabs can't run different courses in parallel. Also refreshed cleanup and mobbin skills with recent findings about the mole tool and CoreSimulator behaviour.

Units 197-201 complete, XP 192,492, streak 146. In parallel, extracted the graphics-reading techniques into a public library, Sextant (nulljosh/sextant), live at https://sextant-20m.pages.dev with a demo you can draw on. Found and fixed a critical bug where a variable leaked into shared helpers and broke the planning function.
