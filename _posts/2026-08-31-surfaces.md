## Sunday (2026-08-31)

Wrapped API and MCP endpoints on five apps, added a public query page to brain, rolled out share across 26 apps, audited monetization, and swept docs for missing READMEs. Fixed a TCC consent loop on macOS and Wordroot's landing page where a missing i18n key leaked to the DOM (i18n.t() returns the key as fallback; kept inline English instead so future keys degrade gracefully). Discovered `wrangler pages deploy dist` skips API Functions because the path argument overrides pages_build_output_dir; correct is just `wrangler pages deploy`. Swept the codebase for the same i18n bug and found it latent in talli and quotestreak with identical patterns where t() returns the key and gets written to el.textContent; nothing rendered yet so no actual leak, but patched both as insurance and committed all three apps.

## Monday (2026-08-31)

Created lec-quiz skill to ingest D2L Pre-Calc 12 quizzes into lexly and added Unit 5 (rational functions, conics), raising the question bank to 96. Rewrote Duolingo skill from pixel coordinates to DOM selectors (80% cost reduction). The grader executable revealed three rendering traps: shuffled options, doubled text, U+2212 minus. Finished the session at 40 lessons total with 2 wrong answers; Grade 8 unit 1 "Scientific notation" now complete with all nodes and trophy, and Grade 6 fully done. The DOM approach with detached solver polling finally made timed lessons workable; found that tool calls timeout around 30 seconds and real pointerdown/mouseup sequences work on sliders when synthetic clicks fail, with the key constraint being to always re-verify slider landings before submit since window resizes mid-run stale the coordinates.
