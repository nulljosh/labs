## Sunday (2026-08-31)

Three apps got API and MCP endpoints. Two weren't blocked on anything technical - they just lived on GitHub Pages, which can't run server code. Wordroot was already on Cloudflare Pages; adding the Functions pattern unblocked a roadmap item about whether to use a database, but the answer was neither since Wiktionary is already the dataset and gets read live in the browser. Quotestreak and Bookrank both moved from GitHub Pages to Cloudflare Pages, repointing DNS and deleting the old workflows, then got the same Functions template running over their JSON files.

**Apps:** Wordroot, Quotestreak, Bookrank
