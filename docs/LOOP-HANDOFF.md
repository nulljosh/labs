# Foreground loop

Read CLAUDE.md, WHITEPAPER.md, docs/RESEARCH.md and roadmap.md. Run tests and both benchmarks before changing an algorithm. Inspect counterexamples before increasing bounds.

Choose one finite experiment. State domain, expected result, independent check and falsification rule. Run it, preserve failures, update measured findings and proof obligations, then stop. Repetition measures reproducibility, not new mathematics. No background jobs, automatic models or automatic Git pushes.
