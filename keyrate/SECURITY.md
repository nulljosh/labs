# Security

## Reporting

Found something? Email **trommatic@icloud.com**. Don't open a public issue for anything exploitable.

You'll hear back within a week. This is a solo side project. No bounty, no SLA, just a reply.

## Supported versions

| Build | Supported |
|---|---|
| Web, keyrate.jaybulb.com | The deployed version |
| iPhone, iPad, Mac (`apple/`) | 2.0.x, once released |
| Android (`kmp/`) | 2.0.x, once released |
| Mac, Windows, Linux desktop (`kmp/`) | 2.0.x, once released |
| Terminal (`tui/`) | 2.0.x |

Plus the tip of `main`. Older builds get no fixes; update instead. None of the builds talk to a network, so the surface is the page and the files they keep on your device.
