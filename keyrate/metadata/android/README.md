# Play listing (fastlane supply layout)

`en-US/title.txt` (30 characters max), `short_description.txt` (80 max) and `full_description.txt` (4000 max) are ready
to paste into Play Console or upload with `fastlane supply --metadata_path metadata/android`. Screenshots go in
`en-US/images/phoneScreenshots/` once the Android build has been walked on a device (roadmap v20). The text matches the
App Store description in `metadata/version/2.0.0/en-US.json`.
