THE INTERESTING EXCEPTION

DNA is only part
of the story.

Two annotations sit outside a single-base explanation. One is Hb Bristol: published research reports a DNA change encoding methionine, followed by protein processing that yields aspartate.

A sequence-only model cannot explain that final protein by translation alone. The mismatch points to the model's boundary.

THE SCIENTIFIC METHOD, IN THE LOOP

A hypothesis is
a beginning.
Evidence is the work.

AI can help ask a sharper question. It cannot turn a plausible answer into a fact. Evidna keeps the distinction visible.

Read the technical whitepaper →
  1. 01

    Observe something real.

    Start with a public reference sequence. Keep its accession, source, and file fingerprint alongside every result.

  2. 02

    Ask. Then challenge.

    A researcher proposes a falsifiable hypothesis. A second AI pass challenges its assumptions and missing evidence.

  3. 03

    Keep an honest notebook.

    Attach an observation and its source. Revisit the hypothesis with that evidence. Keep the old version, too.

FIRST EXPERIMENT / IN SILICO

# Clone the lab
git clone https://github.com/nulljosh/labs/tree/main/evidna
cd evidna

# Read the DNA. Trace the change.
uv run evidna.py analyze

# Ask the researcher and skeptic*
uv run evidna.py hypothesize

* Requires a signed-in Claude CLI. Two sequential Haiku calls. Public analysis is sent to the model.
