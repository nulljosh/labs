## Note to the editor (the "Discussion" box)

The 5-state list of ones counts comes from a plain tree walk of all 5-state machines from a blank tape with no non-halting deciders, cut at 2000 steps (plainwalk.c), plus the 333 halting branches that run past step 2000. The walk's halting count plus the weight of those 333 branches equals A004147(5) = 26751695615616, so no halting machine is missed. The same walk gives Sigma(1..4) = 1, 4, 6, 13 and all 37 current terms. A second program with its own code and non-halting deciders (halters.c) gives the same ones counts up to step 2000, and the ones counts of the long halters match the 5-state machines listed in Michel's survey (arXiv:0906.3749). Every witness in the linked file was rerun from blank by a separate simulator. The program was written with the help of an AI coding assistant; I checked the results as described.
