# OEIS A399346 (Placid Platypus): where the edit stands

A399346 is PP(n), the fewest states a 2-symbol Turing machine needs to halt from blank with exactly n ones. OEIS had 37 terms.

## Submitted 2026-10-28, waiting on an editor

From Joshua's account: the DATA line extended to 130 terms, a b-file for n = 1..130, the comment and example lines below, and cross-references to A004147 and A337805.

    a(n) <= 5 exactly for n <= 73: the halting 5-state machines leave 130 distinct numbers of ones, every number from 0 to 73 and then 75 to 83, 86 to 91, 96 to 99, 104 to 106, 111, 112, 124, 125, 153, 154, 156 to 165, 167, 168, 207, 208, 215, 216, 239, 240, 500, 501, 1470, 1471, 1914, 1915 and 4095 to 4098. So 74 is the smallest number of ones no 5-state machine leaves, and a(74) = 6.
    Each a(n) = 6 above is witnessed by a 6-state machine made from a 5-state one by sending its halting transition to a new state. - Joshua Trommel, Oct 28 2026

    a(74) = 6: no 5-state machine halts with exactly 74 ones, and 1RB1RF_0RC0RE_1LC0LD_1RA0LD_0RB1RD_0RZ1RC does.

Note to the editor, in the Discussion box: the 5-state list of ones counts comes from a plain tree walk of all 5-state machines from a blank tape with no non-halting deciders, cut at 2000 steps (plainwalk.c), plus the 333 halting branches that run past step 2000. The walk's halting count plus the weight of those 333 branches equals A004147(5) = 26751695615616, so no halting machine is missed. The same walk gives Sigma(1..4) = 1, 4, 6, 13 and all 37 current terms. A second program with its own code and non-halting deciders (halters.c) gives the same ones counts up to step 2000, and the ones counts of the long halters match the 5-state machines listed in Michel's survey (arXiv:0906.3749). Every witness in the linked file was rerun from blank by a separate simulator. The program was written with the help of an AI coding assistant; I checked the results as described.
