# Noema computer science

Busy Beaver: among all Turing machines with n states and two symbols that eventually stop, which runs longest, and which leaves the most ones on the tape?

```sh
python3 -m unittest discover -s tests
python3 busy.py 4
```

The enumerator builds machines as a tree, defining a transition only when a run reaches it, and fixes the first move to the right because the mirror image behaves the same. It reproduces the published values for one through four states: 1, 6, 21 and 107 steps, and 1, 4, 6 and 13 ones. Six deciders remove holdouts from the search, each one a proof that a partial machine never halts from a blank tape. A repeated configuration is a cycle. A translated cycler is a run where the head reaches a new edge in a state it had at an earlier edge on that side, and the tape behind it repeats shifted. Backward reasoning closes the set of configurations that can reach an undefined transition backwards under the defined rules, and the blank tape is not in it. The closed tape reads the tape as runs of one- or two-symbol words, and checks that no reachable run reads an undefined transition. The block tape does the same over blocks of two cells, which keeps the parity of a run of ones that the cell version loses. The n-gram closed position set abstracts a configuration as a state, the symbol under the head, and the two nearest blocks on each side, where a block is two aligned cells. It keeps every two-block window seen on each side, and a move pops a new block from one side only when the window it forms is already seen. Sweeps repeat until the sets stop growing; if no reachable abstract configuration reads an undefined transition, the machine never halts. One-cell windows of length two to twelve prove none of the four 3-state holdouts, while two-cell block windows prove all four. The last four only run on holdouts at the cap. Each one covers every tape a real run can make, so a machine that really halts is never marked. At 3 states, cap 200, holdouts fall from 3,119 to 92 with translated cyclers, then backward reasoning proves 55, the closed tape 28, the block tape 5 and the n-gram closure 4, which leaves none. So BB(3) = 21 and Sigma(3) = 6 are decided by this code. That is still a reproduction of Lin and Rado (1965), not new work. At 4 states, cap 300, holdouts fall from 521,462 to 20,569 with translated cyclers, then to 1,539 with backward reasoning, the closed tape and the block tape, then to 643 with the n-gram closure. The run takes about 28 seconds. The 4-state maxima stay bounded observations until those 643 are decided. Soundness check: none of the 88 machines the backward, closed-tape and block-tape deciders flagged at 3 states halts within 100,000 steps when run with no deciders, and none of 2,000 sampled from the 19,030 they flagged at 4 states halts within 20,000. The n-gram closure flagged 4 machines at 3 states, and none of them halts within 1,000,000 steps with no deciders. It flagged 896 at 4 states, and none of those halts within 50,000 steps (all 896 were checked, since the sample is capped at 2,000). The maxima do not move: 1, 6, 21 and 107 steps, and 1, 4, 6 and 13 ones. BB(5) = 47,176,870 was proved in 2024 by the bbchallenge collaboration with a Coq-checked proof; that is the frontier this lane reads toward, not one it claims.
