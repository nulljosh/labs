# Noema computer science

Busy Beaver: among all Turing machines with n states and two symbols that eventually stop, which runs longest, and which leaves the most ones on the tape?

```sh
python3 -m unittest discover -s tests
python3 busy.py 4
```

The enumerator builds machines as a tree, defining a transition only when a run reaches it, and fixes the first move to the right because the mirror image behaves the same. It reproduces the published values for one through four states: 1, 6, 21 and 107 steps, and 1, 4, 6 and 13 ones. Five deciders remove holdouts from the search, each one a proof that a partial machine never halts from a blank tape. A repeated configuration is a cycle. A translated cycler is a run where the head reaches a new edge in a state it had at an earlier edge on that side, and the tape behind it repeats shifted. Backward reasoning closes the set of configurations that can reach an undefined transition backwards under the defined rules, and the blank tape is not in it. The closed tape reads the tape as runs of one- or two-symbol words, and checks that no reachable run reads an undefined transition. The block tape does the same over blocks of two cells, which keeps the parity of a run of ones that the cell version loses. The last three only run on holdouts at the cap, and every merge they make widens the tapes they cover, so a machine that really halts is never marked. At 3 states, cap 200, holdouts fall from 3,119 to 92 with translated cyclers, then to 4: backward reasoning proves 55, the closed tape 28 and the block tape 5. The 4 are unchanged at caps 400 and 1000. Their tapes grow in a way the finite abstractions here cannot prove non-halting, so BB(3) is not yet fully decided; the bbchallenge bouncer write-up shows the kind of parametric induction that would be needed. At 4 states, cap 300, holdouts fall from 521,462 to 20,569 with translated cyclers, then to 1,539, and the run takes 23 seconds. Until every holdout is decided, the maxima are bounded observations, not proofs. Soundness check: none of the 88 machines the new deciders flagged at 3 states halts within 100,000 steps when run with no deciders, and none of 2,000 sampled from the 19,030 flagged at 4 states halts within 20,000. BB(5) = 47,176,870 was proved in 2024 by the bbchallenge collaboration with a Coq-checked proof; that is the frontier this lane reads toward, not one it claims.
