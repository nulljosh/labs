Written proof · candidate

Frustrated magnets, counted exactly

Put magnets on a triangle grid that wraps around like a donut, each wanting to point opposite its neighbours. No arrangement can please every triangle, so there are huge numbers of equally good ones. We proved an exact formula for how many, for any grid size. It runs in milliseconds where counting by hand takes hours. Its pieces turn out to be Wendt's determinant, a number studied for over a century in work on Fermat's Last Theorem. That link is the part we have not found anywhere else.

Written proof · likely known

A prime hidden in the count

When 2n+1 is a prime number, that prime divides the n by n magnet count again and again, at least ceil(n/2) - 1 times. Checked for every case up to n = 120 and proved for all n. It probably follows from classical results about Wendt's determinant, so we treat it as a corollary, not a discovery.

The argument

Decided by code · reproduces 1965

The 3-state Busy Beaver is 21 steps

Among all tiny computers with three states, the longest-running one that still stops runs 21 steps and writes 6 ones. Our program settles every machine: each one either stops within 21 steps or is proved to run forever by a decider that cannot be fooled. This matches Lin and Rado's 1965 result. For four states, 27 machines are still open.

Machine-checked in Lean

Some Collatz starts always drop

Collatz: halve even numbers, triple odd ones and add one. For every start above 1 of the form 4k+1, and every start of the form 32k+11 or 32k+23, the sequence falls below where it began. Lean, a proof checker, verified all three for every k, with no assumptions beyond the standard ones. This says nothing about the full Collatz problem, which stays open.
