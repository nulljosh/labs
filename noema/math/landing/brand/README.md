# Noema brand kit 1.0

An independent mathematics lab. Curious, precise, candid. Say what was checked, the bound, and what remains unproved. Prefer “checked through 10,000” to “solved.”

## Color

Base colors come directly from https://clrs.cc. Blue #0074D9 is the signature. Navy #001F3F is the ink. White #FFFFFF is the canvas. Aqua #7FDBFF is a supporting illustration color. Silver #DDDDDD is a border and dark-surface text color. Gray #AAAAAA is decorative only on white. Maroon #85144B identifies failed rules with explicit text. Olive #3D9970 is a decorative status dot with a written label. Tints are alpha blends of these base colors, not new hues.

## Logo constraints

The symbol is an N inside a circle: a thought examined within a boundary. Construct it on a 64-unit square. N endpoints are at (14,14), (14,50), (50,50), (50,14), with a 6-unit rounded stroke. The circle is centered at (32,32), radius 14, stroke 2. Use one solid color per mark. Keep at least 8 units of clear space. Never stretch, rotate, add gradients, shadows or new decoration. Minimum full-symbol size: 24px. At 16–23px use symbol-small.svg, which removes the circle and uses a 2px N stroke on a 16-unit grid.

Blue on white is primary. Navy on white is monochrome. White on navy is reversed. The SVG wordmarks use live Arial/Helvetica text; final letter shapes depend on the viewer's fonts. Symbol geometry is fully vector and font-independent. No trademark availability check has been performed.

## Type and components

Georgia for display headings and numeric records. System sans for body, forms and navigation. Body text at least 14px; supporting text 12px; short uppercase metadata can be 10px. Use 4/8/12/16/24/32/48/64 spacing. Control radius 4px; panel radius 8px. Focus ring 3px blue with 5px offset. Interactive controls at least 44px high. Tabs support arrow, Home and End keys. Respect reduced-motion preferences. Graphs need a textual summary and a labelled scale.
